One fortune-cookie line for make.fun's "Fortune Cookie for an AI Agent" bounty: a tall, dark stranger turns out to be the agent's own error log, waiting for it. `main.py` prints the line and writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
